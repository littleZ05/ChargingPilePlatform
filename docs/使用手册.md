# 使用手册

适用于本轮重构后的课程版本。使用前请同时阅读需求验收追踪中的数据模拟边界和在线地图待验收项。

## 环境与构建

Ubuntu 22.04、Qt 6.2.4；依赖 Widgets、Network、Sql、Charts、WebEngineWidgets 和 SQLite 驱动。使用 qmake6 和 make。WebEngineWidgets 是导航内嵌网页新增依赖，缺少时需安装 qt6-webengine-dev。

```bash
cd /home/bit/桌面/dongruan_ws/ChargingPilePlatform
python3 tools/verify.py
```

命令会构建服务端、用户端和测试工程，输出保存在 `build-verification/`。主程序分别在 `src__pcserver__pcserver/PcServer` 与 `src__userclient__userclient/UserClient` 子目录。测试采用独立数据库和应用配置目录。

## 启动与账户

先在图形桌面终端运行 PcServer，再运行 UserClient。管理员为 admin / 123456；用户输入11位手机号免密登录，未注册自动注册并获得100元演示余额。

服务端默认数据库在可执行程序旁边，可用 `PCSERVER_DB_PATH` 指定。先停止程序再备份库，服务端与客户端须同时升级。旧库含同用户或同桩的多个活动订单时，升级拒绝并回滚，不会自动删除订单；需要按实际业务核对冲突。

## 充电与结算

1. 登录后选择充电站、正常空闲电桩，发起充电。
2. 服务器确认建单并锁定本单单价后开始计时。电量按功率和时长模拟。
3. 点击结束并结算，界面显示待确认；只有服务器成功回执后显示结算结果。
4. 余额不足时去“我的”充值，然后返回重试结算。充值为模拟支付，余额写入数据库。
5. 断线或关闭后重新登录，系统恢复未完成订单并引导结算。同用户不能同时另开活动订单。
6. 请求结果不确定时，重连会用原请求编号核实结果，避免重复扣费。

已有订单允许在账号冻结或电桩健康故障后合理结算；冻结用户和异常电桩不能新建订单。充电中折扣变化不改变该单已经确认的价格。

## 用户资料

在“我的”编辑昵称，等待服务器保存结果。头像选择 PNG/JPEG 图片，尺寸不超过2048像素；服务器验证并缩放保存。重新登录可读取已保存资料及近期订单。客户端绝对文件路径不会作为共享头像路径发送。

## 地图导航

在首页定位并选择目标站，进入导航页。顶部选择驾车或步行，预览路线后点击“打开腾讯地图导航”，在应用内网页查看规划；“在浏览器打开”作为备用入口。

腾讯地图网络请求需要网络及适用的 `TENCENT_MAP_KEY`。网络失败时静态预览和网页可能不可用，直线估算会明确标记为估算，不代表实际道路路线。坐标异常时先重新定位。

## 自愈告警

自愈检测会记录最近已处理样本；三条低功率记录触发预警和模拟重启，之后再出现三条新异常样本才升级故障。重复扫描或服务重启不会把旧样本算作新证据。新正常样本解除自愈故障。

这是模拟运维，未向物理电桩发送重启指令。检测不会释放仍有活动订单的桩。演示注入按钮用于演示样本，不能作为真实设备采集证据。

## 预测、推荐与阈值校准

负荷预测页可选择未来1、3、6、24小时，计算在后台线程执行；切换站点或模型后，旧计算结果不会覆盖新选择。峰值达到容量80%时显示运营预警。

首页默认距离优先，可切换“低拥堵推荐（未来1小时）”。预计空闲桩数按预测功率占额定容量的比例估算，不是排队或预约承诺。缺少有效功率记录时不参与预测推荐，定价维持基础价；演示曲线仅用于图表展示。

在自愈页选择正常电桩，点击“重算正常阈值”。系统读取最近100条功率记录、剔除已知异常及离群值，至少保留6条才保存。低功率阈值为正常均值的80%，高控制限按相邻样本移动极差估计；高控制限目前用于记录，自动告警仍按连续低功率规则执行。出现预警或故障时应先排查，不能直接重算阈值掩盖异常。

缺测说明：历史窗口内部缺测小时采用线性插补，窗口两端沿用最近的实测值；实测零功率保留为零。图表显示插补小时数，大屏接口提供 `forecast.imputed_hours`。计价与推荐要求近12小时至少8小时有记录；图表可用较稀疏数据展示趋势，但不因此获得计价资格。当前按小时样本均值估计功率，不能替代真实电表连续计量。

## 独立演示入口与数据保护

```bash
./tools/demo_5min.sh              # 构建更新后启动，保留已有演示数据
./tools/demo_5min.sh --reset      # 先备份再重置独立演示库
./tools/demo_5min.sh --build-only # 无桌面环境只验证编译
./tools/seed_demo_data.sh         # 显式重置独立演示库，不启动界面
```

演示数据库固定在 `build-demo/chargingpile.db`，与默认程序数据库分开。重置前请关闭PcServer；脚本不会自动杀死其他进程。新库构建或外键检查失败时旧库不变。备份保存在同目录，文件名含时间戳。首次创建独立演示库会填入5站37桩数据；之后普通启动保留订单和余额。每次启动均运行qmake/make增量构建，避免使用过时二进制。

## 安装依赖与单独运行

```bash
sudo apt install qt6-base-dev qt6-charts-dev qt6-webengine-dev libqt6sql6-sqlite g++ make python3
./tools/demo_5min.sh --build-only
./build-verification/src__pcserver__pcserver/PcServer
./build-verification/src__userclient__userclient/UserClient
```

单独运行与独立演示使用不同数据库路径。若需指定正式数据，可在启动服务端前设置 `PCSERVER_DB_PATH=/你的路径/chargingpile.db`。默认TCP为9999，大屏HTTP为8890；可分别通过 `PCSERVER_PORT` 和 `PCSERVER_DASH_PORT` 修改，用户端的PCSERVER_PORT需一致。默认用户端连接127.0.0.1。

## 管理后台十个页签

| 页签 | 操作与含义 |
|---|---|
| 销售业绩 | 查看今日、本月、总营收，切换7日/30日曲线；只汇总已结算订单 |
| 负荷预测 | 选择电站、历史窗、模型与预测时域；查看峰值、来源、插补量与负荷预警 |
| 电桩状态 | 查看空闲、充电中、故障数量及占比；管理操作不得破坏活动订单 |
| 充电站管理 | 查看站点、在线率、站内桩，新增站点及模拟电桩 |
| 用户管理 | 手机号模糊搜索、冻结/解冻；冻结限制新业务，允许既有订单结算 |
| 充电桩管理 | 查看类型、功率、累计次数/时长，维护无活动订单的桩；历史订单保留 |
| 价格策略 | 查看折扣、预测依据及决策时间，手动触发重算 |

| 交付自检 | 查看数据库与服务检查结果；该页通过不代替完整回归 |

## Web大屏

服务端登录成功后打开 `src/webdashboard/index.html`。大屏每10秒拉取 `http://127.0.0.1:8890/api/dashboard/overview`，ECharts资源在仓库内。断线时查看页面的数据源/连接提示，离线演示数字不能当作实时营收。自定义HTTP端口时，可在页面URL后附加 `?api=http://127.0.0.1:新端口/api/dashboard/overview`，无须修改源码。较矮窗口可滚动查看完整图表。

## 故障排查与交付包

- 无图形会话：在桌面终端运行；自动化采用offscreen，不代表可替代人工操作验收。
- 端口被占：关闭此前演示实例，勿盲目终止不相关进程。
- 升级失败：保留错误日志和数据库备份，核查同用户/同桩的重复活动订单；不会自动删除订单。
- 结算不确定：保持原订单，重连核实；不要新建订单绕过结算。
- 地图失败：检查网络与TENCENT_MAP_KEY；可用浏览器备用入口，直线估算不是道路路线。
- GitHub访问失败：本机需要 `env -u LD_PRELOAD git pull --ff-only`，SSH走443。

`python3 tools/package_delivery.py` 只接受当前干净提交及对应的全量通过报告，输出到build-delivery。源码包在安装Qt依赖的Linux环境构建，附测试证据和SHA256清单；不是免安装Qt的通用二进制包。
