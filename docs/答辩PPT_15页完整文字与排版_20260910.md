## P14 · 创新点① 闲时动态计费（预测驱动）

**页面文字**
- 标题：创新点① 非高峰"反向激励"动态计费
- 痛点：原计费是固定单价，既无法引导错峰，也缺乏价格弹性
- 方案：
  - 机器学习预测**未来 1 小时空闲率**，当某电站空闲率 **> 60%** 时，自动将该站价格下调（如 **8 折**）
  - 优惠实时推送到用户端电站详情页，标注**"闲时特惠"**徽标
  - 空闲率回落则自动恢复基础价，形成"预测 → 定价 → 用户端展示"的业务闭环
- 技术：预测值写入数据库"电站营销策略表"，服务器端价格策略引擎按规则浮动

**排版方案**
- 顶部一条横向闭环链路图：负荷预测 → 价格策略引擎 → 营销策略表 → 用户端"闲时特惠"。
- 下方左右对比卡：左"空闲率 80% → 打 8 折（闲时特惠）"，右"空闲率 30% → 恢复基础价"。
- 用深绿高亮"8 折""闲时特惠"。

## P15 · 创新点② 异常自愈告警体系

**页面文字**
- 标题：创新点② 基于异常检测的"自愈"告警
- 痛点：原故障处理是"人工上报 + 手动重启"，属于被动响应
- 方案：
  - 用历史充电功率数据建立**每根桩的正常波动阈值**（移动平均极差法），离线算好存回数据库
  - 服务器端"自愈检查"定时任务把实时数据与阈值对比，做**正常 / 预警 / 故障**分级
  - 当某桩**连续 3 次**功率低于历史均值 20%，自动标记"需检查"并**触发一次模拟远程重启**，无需人工点击
- 价值：把"充电桩管理"的远程重启从人工操作升级为平台自愈能力

**排版方案**
- 左侧一条纵向时间线：连续 3 次低功率 → 命中阈值 → 标记"需检查" → 自动远程重启 → 恢复正常、计数清零。
- 右侧放自愈日志截图 + 三级阈值示意（正常/预警/故障三色进度条）。
- 标题下副标题："从'人找故障'到'平台自愈'"。
