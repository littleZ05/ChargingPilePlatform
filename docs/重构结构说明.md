# 重构结构说明

## 当前分层

- `mainwindow.cpp`：窗口生命周期、刷新协调、管理员操作入口。
- `mainwindow_pages.cpp`：后台页签及控件布局。
- `mainwindow_support.cpp`：表格、图表和登录对话框辅助函数。
- `mainwindow_socket.cpp`：帧消息路由、会话身份与应答；写业务委托 ChargeService。
- `mainwindow_p.h`：仅供窗口实现使用的内部状态。
- `admin_repository.h/.cpp`：后台查询与管理写入接口，界面代码不再包含该类实现。
- `admin_demo_seed.cpp`：既有演示数据初始化，单独隔离以便后续改为显式演示入口。
- `stationstore.cpp`：数据库生命周期、统一资源schema迁移、站点及预测聚合。
- `stationstore_orders.cpp`：既有订单、用户访问接口，保持调用方兼容。
- `charge_service.cpp`：身份校验后的订单、资料、充值事务及持久化回执。
- `forecast_async.cpp`：只接收值对象快照的后台算法计算。

原主窗口约3200行，现主协调文件约720行；拆分后的手写源文件均控制在1000行以内。拆分按职责进行，不把实现文件相互include拼接。公共头文件声明接口，项目工程文件显式登记编译单元。

后台原先复制的建表SQL已经移除，改用 StationStore 的资源schema与迁移入口。主程序及带StationStore的窗口通过 attach 共享同一数据库连接，普通启动不调用演示用户/订单灌库。无注入上下文的旧构造入口仍保留兼容路径。管理写入在同一事务内维护统计；活动订单禁止改桩或重启，有历史订单禁止删桩。

## 验证原则

纯拆分复用原模块回归；迁移入口变化重点验证后台初始化、登录、用户管理、站桩管理和Socket业务。任何行为变化另行列明并增加针对性用例，不以大量结构镜像测试替代业务验证。
