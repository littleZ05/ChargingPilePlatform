## 3 模块详细概述（关键模块）

### 3.1 充电用户端模块（Linux + Qt，负责人：葛伊诺）

#### 3.1.1 模块功能定义

| 序号 | 功能点 | 功能点详细内容 |
|---|---|---|
| 1 | ▲ 附近充电站查询 | 下拉选区域/手输地址（模拟 GPS）→ 腾讯地图转经纬度 → 按距离排序展示电站卡片（站名/电价/桩数/空闲/距离）→ 查看站内电桩明细 |
| 2 | ▲ 一键导航 | QWebEngineView 加载腾讯地图，起终点路线规划（驾车/步行），无网降级提示 |
| 3 | ▲ 用户信息维护 | 手机号免密登录/自动注册、头像上传、昵称修改、余额充值（模拟） |
| 4 | ▲ 电动汽车充电 | 未完成订单检查 → 选空闲桩 → 充电 → 计费 → 结算，余额实时更新 |

#### 3.1.2 模块结构

| 模块/类 | 模块类型 | 概要说明 |
|---|---|---|
| ClientWindow | 界面（View） | 主界面、页面切换、日志/状态显示（.ui + QSS） |
| NetClient | 内部模块 | QTcpSocket 封装：连接、请求帧收发（复用 common 协议约定） |
| StationService | 内部模块 | 电站/电桩查询请求组装与结果解析 |
| UserService | 内部模块 | 登录/注册/资料/充值请求 |
| ChargeController | 内部模块 | 充电流程状态机（检查-充电-结算），驱动进度显示 |
| TencentMapView | 接口 | QWebEngineView 封装腾讯地图（查询与导航） |

#### 3.1.3 关键动作流程（充电时序示意）

```text
用户点击充电 → ChargeController 请求服务器查未完成订单
            → 有未结算订单：弹窗提示并跳结算页
            → 无订单：加载空闲桩列表 → 选桩 → 服务器建单(charging)
            → 模拟充电中 → 结束 → 服务器结算(amount/state=已完成)
            → 用户端刷新余额并提示
```

## 4 接口说明

### 4.1 数据结构定义

- 公共契约：`src/common/common.h` —— 端口(9999)、`PileState/OrderState/HealLevel`、
  `MsgType`（心跳/查站/订单上报…）、`Pricing/SelfHeal` 规则常量（组长已入库）；
- 协议帧：`[type:1B][payloadLen:2B][payload:JSON 或二进制]`；
- 错误码：`src/common/error_utils.h`（错误码 + 中文文案 + 手机号/金额校验），
  界面层经 `ui/error_notify.h` 统一弹窗/状态栏提示。

## 5 关键技术选型与约束

- 客户端/服务器端：Qt 6.2.4 Widgets + Network + Sql（服务器端含 Charts）；qmake 工程；
- 数据库：SQLite（QSQLITE），金额以分存储；所有 SQL 参数绑定；
- 界面：.ui + 布局管理器 + QSS；图标走 .qrc；
- 并发：Qt 信号槽事件驱动为主，耗时任务按需移入线程（QThread/moveToThread）；
- 地图：腾讯地图 Web API + QWebEngineView，无网降级提示。
