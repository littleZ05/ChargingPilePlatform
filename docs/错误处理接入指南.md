# 错误处理接入指南（NO.20，负责人：张芮萌）

## 分层约定

| 层 | 文件 | 职责 |
|---|---|---|
| 纯逻辑 | `src/common/error_utils.h` | 错误码、中文文案、输入校验（手机号/金额等） |
| 界面层 | `src/common/ui/error_notify.h` | 统一弹窗 / 状态栏文案 |

## 用法示例

```cpp
#include "error_utils.h"      // 校验与错误码
#include "ui/error_notify.h"  // 展示（界面层）

// 1) 输入校验 + 状态栏提示（不打断操作）
if (!cp::isValidPhone(phoneEdit->text())) {
    statusBar()->showMessage(cp::statusErrorText(cp::AppError::PhoneInvalid), 3000);
    return;
}

// 2) 强提醒场景（数据库/网络错误）：弹窗
if (!db.open()) {
    cp::showAppError(this, cp::AppError::DbError, db.lastError().text());
    return;
}

// 3) 除零/计算错误由模型层返回错误码，界面统一映射
//    例：CalculatorModel 风格，返回 false + AppError，界面弹窗或状态栏提示
```

## 约定

1. 错误提示一律走本封装，**不要**在业务代码里直接 `QMessageBox::about(...)`；
2. 需要新增错误类型时，先在 `error_utils.h` 的 `AppError` 增加枚举与文案，再在界面使用；
3. 测试文件：`src/common/tests/`（error_utils_tests），新增校验函数时同步补单测。
