# 第二阶段数据清洗

汇报制作请看 [PPT同学制作指导](PPT同学制作指导.md)。共享目录 `大数据开发/07.清洗汇报材料/` 已提供离线交互页面和10张可插入PPT的高分辨率PNG。

可视化可从已验证的清洗结果重新生成（先校验manifest中的全部哈希）：

```bash
python3 stage2/cleaning/build_presentation.py --input 清洗结果目录 --output 数据清洗可视化.html
```

生成页面内嵌本地ECharts及聚合数据，直接浏览器打开，不需要服务器或网络。支持切换分析维度和指标、下载PNG。仅含聚合/审计统计，不包含用户标识。它是清洗汇报辅助材料，不代替第二阶段业务大屏。

依据《数据清洗基本流程-完整版.docx》六步流程。第二阶段必做是多维分析与Web大屏，预测选做；本清洗为大屏提供有明确口径的明细与聚合，不修改第一阶段Qt项目。

## 六步和产物

1. 探查：全量字段类型、范围、缺失、不同值数量写入audit/profile_before.json。
2. 质量评估：完整性、唯一性、有效性、一致性、准确性、时效性逐项说明，不给未经依据的“100分”。
3. 制定规则：见下表；不盲目删异常/填均值，保留未知含义。
4. 执行：ODS原样复制，DWD标准化明细，错误隔离到quarantine，逐行动作到audit。
5. 校验：输入=保留+隔离；五维聚合行数/金额/电量对账；原始哈希不变；同输入重复运行输出可复现。
6. 报告：质量报告.md、manifest.json（输入/输出SHA256）、规则数量、可选Excel。

## 规则清单

| 规则 | 处理 | 原因 |
|---|---|---|
| R01 格式 | NFKC、首尾空白及BOM/零宽空格规范化；ODS不动 | 消除格式噪声，保留追溯 |
| R02 去重 | 全行重复仅保留一份；站点/会话主键冲突全部隔离 | 不随意选一个冲突版本；电池esd身份未核实不按其单列去重 |
| R03 站点 | 设备数正整数、必要标识/描述、更新日期格式校验 | 无效维度不用于关联；地理真实性未核实 |
| R04 会话 | 有限非负电量/费用、正时长、起止先后、站点关联校验；内部不一致标记 | 非法关键数值隔离，其他未知问题保留 |
| R04 年份 | 0014/0015保留raw；calendar_date为空，禁止真实日期趋势 | 加2000年星期也一致，不能据此证明年份；时区也未知 |
| R04 零值 | 55条零电量、3016条零费用保留并标记 | 不知道是否免费、失败或缺失，不按假设电价补收入 |
| R04 枚举 | 设施保留1/2/3/4原编码；星期one-hot核对 | 没有可靠码表，不把4合到3 |
| R05 电池 | 正负电流保留；绝对值超过40A只标记；SOC/电压/温度大小校验 | 电流符号可能代表充电方向；课堂阈值不是已证明错误界限 |
| R05 时间 | raw保留，timestamp空，time_series_usable=0 | 2.02E+13不能还原采样间隔；不凭行号造时序 |
| R05 单位 | available_energy保持来源单位待核；瞬时功率绝对值=V×abs(A)/1000 | 不把功率当能量，不从未知间隔积分 |

## 大屏字段口径

- `source_row`是原CSV的行号（含表头，因此从2开始）。ID一直是字符串。
- `session_count`是会话次数，包含零电量；`positive_energy_count`是正电量会话次数，不是成功支付订单数。
- `total_kwh`是原始合法电量之和；`source_fee_total_unverified`是原字段费用求和，币种/语义未核实，禁止标“真实营收”。Decimal计算不引入float长尾。
- `duration_hours_total`为时长累计；超过24小时保留flag，不静默裁剪。
- 小时/星期聚合仅包括对应校验通过记录；维度有效性筛选不同，今后有坏数据时不要要求每个图总数无条件相同。
- `calendar_date`空的会话不做真实日/月趋势；可做来源小时/星期分布，说明它们不构成已证实的现代日期。
- battery不与sessions关联：esd和sessionId重合只能提示待核，不能证明是同一实体。
- 输出仍含用户标识，内部分析保留；公开展示只使用聚合结果，不展示原user_id。
