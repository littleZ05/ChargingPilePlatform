# 答辩演示脚本：依次弹出窗口（第二阶段）

一条命令即可演示：程序会**自行启动大屏服务**，然后按顺序弹出 12 个窗口——前 7 个是七环节的效果图，后 4 个是**真实大屏**（并自动切到筛选联动、电池样本、数据质量视图），最后一张是结束页。

## 运行

```bash
cd /home/bit/桌面/dongruan_ws/ChargingPilePlatform
bash stage2/defense_demo.sh              # 手动推进（推荐答辩现场使用）
bash stage2/defense_demo.sh --auto 25    # 每 25 秒自动翻页（也可随时按空格手动推进）
bash stage2/defense_demo.sh --selftest   # 自检：把 12 帧导出成 PNG，验证素材与服务
```

首次运行会自动编译演示程序（约 10 秒，产物在 `build-stage2-tools/`）。

## 按键

| 按键 | 作用 |
|---|---|
| 空格 / → / 回车 / PageDown | 下一个窗口 |
| ← / 退格 | 上一个窗口 |
| R | 从头开始 |
| Esc / Q | 退出（同时关闭由本程序启动的大屏服务） |

## 现场建议

- 提前 5 分钟运行 `bash stage2/defense_demo.sh`，停在封面，等讲到第二阶段任务时再按空格。
- 窗口是**真实服务**渲染的，断网也能跑（ECharts 为本地离线库，数据来自本地清洗结果）。
- 若现场不方便投屏演示，用 `--selftest` 先导出 12 张 PNG（`defense-selftest/`），直接插进 PPT 讲。
- 兜底：共享目录 `大数据开发/07.清洗汇报材料/数据清洗可视化.html` 双击即可打开，无需服务。

## 参数

```bash
--data <清洗结果目录>   默认 /home/bit/vmware_share/大数据开发/06.清洗结果_20260916_v2
--model <model.json>    默认 build-stage2/run-demo/model.json（缺失时自动生成）
--assets <素材目录>     默认 stage2/docs/PPT素材
--port <端口>           默认 8765
--auto <秒>             自动翻页间隔；0 表示仅手动
--no-server             不自动启动服务（用已有服务）
```
