# 小组录屏脚本（第二阶段，8–10 分钟）

要求：MP4，只录第二阶段内容，可提前录制。建议 1600×1000 窗口、全屏无桌面图标，录制前关闭聊天软件。

## 录制前准备（3 分钟）

```bash
cd /home/bit/桌面/dongruan_ws/ChargingPilePlatform
# 1) 跑全链路（约 30 秒），产物在 build-stage2/run-<时间戳>/
bash stage2/run_all.sh          # 结束后 Ctrl+C 停掉大屏
# 2) 重新用同一份清洗结果起服务（保证录屏时数据版本固定）
python3 stage2/dashboard/server.py \
  --data /home/bit/vmware_share/大数据开发/06.清洗结果_20260916_v2 \
  --model build-stage2/run-<时间戳>/model.json
# 3) 浏览器打开 http://127.0.0.1:8765
```
