# 第二阶段运营分析接口与指标约定

本模块独立于第一阶段SQLite协议，仅只读清洗产物DWD。使用Python标准库本地HTTP服务，绑定127.0.0.1，不向浏览器公开原始文件或用户ID。初次加载验证manifest中的三张明细哈希与行数；不一致则拒绝启动，不退回随机演示数据。

- `/api/health`：服务及数据版本。
- `/api/options`：全量筛选枚举、站名映射。
- `/api/overview`：支持station_id、facility_type、platform、weekday、energy组合交集筛选；energy为all/positive/zero。无效或重复参数返回400，不支持的API返回404。
- `/api/battery`：独立电池样本的分布与匿名SOC/电压散点，不受会话筛选影响，不关联esd与sessionId。

指标：会话次数包括零电量，正电量不等于成功支付；桩数不能从会话数推算。总电量和源费用使用Decimal求和、JSON传十进制字符串，均值空集合返回null。源费用不称为营收，币种未知。总时长保留超过24小时记录，分箱最后独立展示。

小时图按0至23补零类别，星期按周一至周日；仅计入对应可用性标记为1的记录。不同校验范围可能导致维度合计不同，应保留覆盖说明，不静默伪造补齐。站点按会话数降序、ID稳定排序，完整列表供前端选择Top N。

不提供真实日期筛选：源年份未经确认。第一阶段模拟经营指标不能混入本模块。界面必须展示数据来源、更新时间含义与口径提示，失联不能继续显示“实时正常”。
